# Go

Go er en sosial treningsapp der du logger økter, følger venner og konkurrerer i ukentlige ligaer.

Denne mappen inneholder en klikkbar prototype med eksempeldata. Åpne `index.html` i en nettleser for å prøve den. Alt du gjør i prototypen lagres bare i nettleseren din.

## Hva prototypen viser

- **Feed:** økter fra de du følger, med «Heia» og kommentarer.
- **Logg økt:** aktivitet, varighet, distanse og innsats (RPE 1–10), med forhåndsvisning av XP.
- **Kalender:** månedsoversikt med symbol for aktivitet og farge etter innsats (grønn lett, gull middels, rød ekstra hard).
- **Rangering:** ukentlig liga fra Bronse til Diamant med opp- og nedrykk, og utfordringer.
- **Profil:** nivå, statistikk, ukesoversikt, merker og egne økter.
- **Innstillinger:** konto, personvern, varsler, tema, enheter, tilkoblede apper og konseptbeskrivelsen.

## Poengsystem

XP = tid (min) × (0,5 + innsats/10) + distansebonus + streak-bonus (5 % per dag, maks 50 %) + 20 for dagens første økt. Tak: 300 XP per økt.

## Videre arbeid

Foreslått teknologi for en ekte app er React Native med Expo og Supabase. Se «Konsept» under Innstillinger i prototypen for plan og åpne spørsmål.
